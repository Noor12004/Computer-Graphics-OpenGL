# Computer Graphics with OpenGL (C++)

My practice programs from the Computer Graphics with C++ module at Liverpool Hope University, using OpenGL with GLFW, GLEW, GLM and SOIL.

| Folder | What it does |
|---|---|
| `01-first-window` | Opens a window with an OpenGL context |
| `02-triangle` | Draws a triangle |
| `03-vertex` | Works with vertex data |
| `04-lab-exercise` | Textured, rotating Earth: sphere mesh, texture loading, shaders and model/view/projection matrices |

`04-lab-exercise` was completed from a starter file provided by the module.

## How to run

Each program needs GLFW, GLEW, GLM and SOIL installed and linked. `04-lab-exercise` includes a Code::Blocks project file (`lab_exercise.cbp`).
